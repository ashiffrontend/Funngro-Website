1. Website Overview

The Funngro Website Revamp is a modern, high-performance two-sided marketplace designed to bridge digital businesses needing agile technical/creative delivery with certified teenagers eager to build portfolio proof and earn milestone income. The architecture was built without heavy single-page application frameworks, utilizing semantic HTML5, pure CSS3, and Vanilla JavaScript to minimize Time-to-Interactive (TTI) and optimize Core Web Vitals.
